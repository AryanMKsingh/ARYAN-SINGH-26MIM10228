# Python Practice Projects

This repository contains a collection of beginner-friendly Python programs, practice exercises, and small mini-projects created for learning and experimentation.

## Overview

The workspace includes scripts for:

- student registration and admission records
- fee calculation and payment tracking
- search and information lookup
- marks and grade handling
- array, list, tuple, dictionary, and string practice
- basic Python file handling and console-based programs


## Features

- Menu-driven console interface
- Student registration and validation
- Search by registration number or details
- Fee estimation and display
- Marks assignment and viewing
- Beginner-level Python practice scripts

## Requirements

- Python 3.x
- No additional external libraries are required for most scripts

## How to Run

Open the project folder in a terminal and run any script using Python:

```bash
python main.py
```

Or run another script such as:

```bash
python main1.py
python grades.py
python search_details.py
```

## Notes

This project is mainly for learning and improving Python skills. Some files are standalone exercises and may not be connected to one another.
