# Python Practice Workspace

This folder contains a collection of beginner-level Python scripts, mini-projects, and exercises focused on core programming concepts such as lists, tuples, dictionaries, arrays, file handling, student records, and simple menu-driven programs.

## Project Purpose

The goal of this workspace is to practice and build confidence in:

- Python syntax and logic
- Data structures like lists, tuples, arrays, and dictionaries
- File reading and writing
- Basic user input and validation
- Simple project organization and script execution

## Main Files

- [main.py](main.py) — main student and fee-related project script
- [main1.py](main1.py) — additional project functionality
- [grades.py](grades.py) — grade and marks related logic
- [fees-calc.py](fees-calc.py) — fee calculation script
- [search_details.py](search_details.py) — detail lookup/search program
- [info-file.py](info-file.py) — file-based information operations
- [Regi_No.py](Regi_No.py) and [Registraion-No.py](Registraion-No.py) — registration number related scripts
- [array.py](array.py), [list1.py](list1.py), [tuple1.py](tuple1.py), [dict1.py](dict1.py) — data structure practice files

## Features

- Console-based Python programs
- Student record and registration handling
- Search and lookup operations
- Grade and fee calculation examples
- Practice on arrays, lists, tuples, dictionaries, and strings
- Beginner-friendly learning exercises

## Requirements

- Python 3.x installed on your system
- No external libraries required for most scripts

## How to Run

Open a terminal in this folder and run a script using Python:

```bash
python main.py
```

You can also run other files like:

```bash
python main1.py
python grades.py
python search_details.py
python fees-calc.py
```

## Notes

This project is mainly for education and practice. Some scripts are standalone examples and are not necessarily connected to each other.
